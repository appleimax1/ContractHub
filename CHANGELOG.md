## Версия 1.2 — Детализация реквизитов и редактирование (Текущая)

**Запрос пользователя:** 
> "Нужна возможность редактировать данные клиента, реквизиты компании, нумератор и поля. Системные поля (номер, дата, реквизиты) должны быть сразу видны в Конструкторе без возможности удаления. Реквизиты компании/клиента надо разбить на отдельные поля (БИН, адреса и т.д.), а банковские реквизиты заводить отдельно списком с привязкой к компании."

**Что изменено/добавлено:**
- **База Данных (Dexie v3):** Обновлена схема. Текстовые поля `requisites` и `director` разбиты на конкретные (`bin_iin`, `address_legal`, `ceo_name`, `phone`, `email` и т.д.). Добавлен массив `bank_accounts` для мультисчетов. Написан скрипт миграции.
- **Редактирование записей (CRUD):** Формы во всех справочниках переписаны для поддержки редактирования существующих записей.
- **Системные поля:** В Конструктор полей добавлен хардкодный список заблокированных системных тегов (Номер, Дата, данные компаний и счетов).
- **Мультисчета в Генераторе:** Добавлены выпадающие списки для выбора конкретного расчетного счета Компании и Клиента при генерации. Системные поля Номер и Дата документа сделаны обязательными.

**Затронутые файлы:**
- `src/db/db.ts`
- `src/pages/CompaniesPage.tsx`
- `src/pages/ClientsPage.tsx`
- `src/pages/NumeratorsPage.tsx`
- `src/pages/FieldBuilderPage.tsx`
- `src/pages/GeneratorPage.tsx`

## Версия 1.1 — Нумераторы, Умные деньги и База Знаний

**Запрос пользователя:** 
> "Добавить вкладку 'База знаний'. Добавить 'Нумераторы' договоров. Сделать так, чтобы 'Ключ тега' формировался сам с помощью транслитерации. Для поля 'Деньги' добавить возможность вводить сумму цифрами, а в документ выводить прописью (с учетом валют)."

**Что изменено/добавлено:**
- **База знаний:** Добавлена новая страница с инструкцией для пользователей.
- **Нумераторы:** Создана новая таблица в БД `numerators` и страница `NumeratorsPage.tsx` для управления счетчиками (с поддержкой префиксов и суффиксов). В Генераторе реализован инкремент счетчика при генерации документа.
- **Транслитерация ключей:** В Конструкторе полей при вводе кириллического названия автоматически генерируется латинский ключ (через функцию `transliterate`).
- **Сумма прописью:** Разработана утилита `numberToWordsRu` для перевода чисел в текст на русском языке (для KZT, RUB, USD). В Генераторе добавлен интерфейс для выбора формата вывода (Цифрами / Прописью).
- **Новые типы полей:** В `FieldBuilderPage.tsx` добавлены типы `money` и `numerator`.

**Затронутые файлы:**
- `src/db/db.ts`
- `src/App.tsx`
- `src/pages/KnowledgeBasePage.tsx` (Создан)
- `src/pages/NumeratorsPage.tsx` (Создан)
- `src/pages/FieldBuilderPage.tsx`
- `src/pages/GeneratorPage.tsx`
- `src/utils/numberToWords.ts` (Создан)

## Версия 1.0 — Базовый MVP

**Запрос пользователя:** 
> Создание базового веб-приложения для генерации .docx и .pdf документов по шаблонам, с локальной базой данных (без бэкенда). Базовое управление компаниями, клиентами и кастомными полями.

**Что изменено/добавлено:**
- **Инициализация проекта:** Настроен React + Vite, TailwindCSS, Lucide-react.
- **База данных:** Настроена локальная база данных IndexedDB через библиотеку `Dexie.js`.
- **Шаблонизатор:** Интегрирован `docxtemplater` для замены тегов в Word-документах.
- **Конвертация в PDF:** Интегрированы `mammoth` (для рендера docx в html) и `html2pdf.js` (для конвертации html в pdf).
- **Справочники:** Созданы базовые страницы для добавления Своих Компаний и Клиентов.
- **Конструктор полей:** Создана логика динамических кастомных полей.

**Затронутые файлы:**
- Вся базовая структура `src/*` (App, компоненты, страницы, engine).
